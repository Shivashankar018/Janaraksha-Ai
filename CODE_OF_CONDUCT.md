# Code of Conduct

JanaRaksha AI is about public safety and public trust. We expect the same care in how we work together.

## Our commitment

We want this project to be welcoming and safe for everyone, whatever their age, background, caste, religion, gender, gender identity, sexual orientation, disability, appearance, nationality, language or level of experience.

## Expected behaviour

- Be respectful and patient, especially with new contributors.
- Give and accept feedback about the work, not the person.
- Write in a way that people with different first languages can follow.
- Protect privacy: never post real complaints, personal data or case details anywhere in the project.

## Unacceptable behaviour

- Harassment, insults, threats or discriminatory language.
- Sharing anyone's personal information without permission.
- Sexual language or imagery.
- Repeatedly disrupting discussions.

## Reporting

Report problems privately to the maintainers through their GitHub profiles. Reports are handled confidentially. Maintainers may remove comments, commits or contributions that break this code, and may block people who break it repeatedly.

## Scope

This code applies in the repository, its issues and pull requests, and any project space or event where someone represents the project.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
